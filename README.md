# AI Engineering Portfolio

Three case studies on applying AI agents to engineering workflows, internal tools, and knowledge management during my internship at an IC design company.

I used Claude Code as a development partner while taking responsibility for requirements, workflow design, integration, evaluation, and delivery.

## Projects

### 1. AI-Assisted Circuit Tuning
[Read the case study](auto-sizing.html)

Designed a reusable Claude Code skill to guide an AI agent through circuit netlist modification, simulation, parameter tuning, and result analysis. The workflow includes structured decision logs, isolated working copies, and human review before applying changes.

### 2. Engineering Department Dashboard
[Read the case study](dashboard.html)

Built and deployed a dashboard that brings project information, meeting actions, and quality tracking into one interface. Users can track their work and submit updates back to the source systems. The department adopted it for daily use.

### 3. Engineering Knowledge Base
[Read the case study](knowledge-base.html)

Developed a structured knowledge base that makes engineering documentation accessible to both people and AI agents, with source-grounded conversational answers and evaluation to identify documentation gaps.

## About These Case Studies

These pages describe the problems, my contributions, implementation decisions, and outcomes. They are project summaries rather than public releases of the internal applications.

Company identifiers, proprietary source code, and internal datasets are not included in this repository.
